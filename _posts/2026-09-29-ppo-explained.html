01全局:四个模型,两种粒度

PPO 阶段显存里同时驻留四个模型,其中两个可训练。它们的输出粒度截然不同 —— 这是理解后面一切的起点。

模型训练输出粒度在损失里的角色
Policy π_θ✅ 是逐 token logprob被优化的对象,产生 ratio 的分子
Critic V_ψ✅ 是逐 token 标量baseline(降方差)+ 价值回归目标
Reference π_ref❌ 冻结逐 token logprobKL 惩罚,防止策略跑飞
Reward Model❌ 冻结整条一个标量唯一的真实反馈来源
一句话记住 RM 给整条回答打一个分,PPO 却要给每个 token 一个梯度。中间那座桥,就是 Critic 的 baseline 加上 GAE 的反向递推。

设定:prompt 长度 P=4,response 长度 T=4,batch 里其它样本靠 padding 对齐。

04GAE:逐 token 的信用分配

前向算 δ,后向累 A。全程无梯度,纯算术。

05PPO-clip:逐 token 的刹车

这是 PPO 的全部精髓,也是唯一一个几何上一眼就能看懂的部分。

ratio_t = exp( logπ_θ(y_t|s_t) − logπ_old(y_t|s_t) ) L_policy = − mean( min( ratio_t·Â_t , clip(ratio_t, 1−ε, 1+ε)·Â_t ) ) mean 的分母 = mask.sum(),ε 通常取 0.2

5.0 ratio·Â 从哪来:三步

① 真目标:J(θ) = E_{ y ~ π_θ }[ R(x, y) ] ← 采样分布随 θ 变,没法直接求梯度 ② 改成「旧策略采样 + 重要性加权」的 surrogate: J(θ) ≈ E_{ y ~ π_old }[ ratio · R ] , ratio = π_θ(y) / π_old(y) 再用 Â 替掉 R:减去 baseline 不改变梯度的期望,只降低方差 ③ 无约束地最大化 ② → 一步就把所有 Â>0 的 token 概率推到 1 TRPO:加约束 KL(π_old ‖ π_θ) ≤ δ → 共轭梯度 + 线搜索,精确但贵 PPO :把约束写进目标里 → clip(ratio, 1−ε, 1+ε),一阶、逐 token、便宜

第 ② 步里 ratio 的作用是「纠正采样分布」:样本是 π_old 采的,却要估 π_θ 的期望,于是每条样本按概率比加权。在 θ = θ_old 处 ratio ≡ 1,加权目标与真目标同值同梯度 —— 这就是它作为 surrogate 的合法性来源,也是 logπ_old 必须在 rollout 时冻结保存的原因:它不是重算出来的,是采样那一刻的快照。

第 ③ 步解释了 clip 的形状:它不是一个 KL 球,而是逐 token、单边的信任域 —— 只在「ratio 朝 advantage 喜欢的方向跑太远」时切断梯度,反方向永远不裁(下面图 6 的不对称正来自这里)。TRPO 用二阶信息换精确,PPO 用一次 min 换速度;代价是信任域只是近似的,所以还需要 ε、epoch 数、KL 监控三者一起兜底(第 8 节)。

10多轮 Agent 场景的逐 token 记账

上面全是单轮的账。轨迹一旦多轮,mask 的形状和 λ 的取值都要重新想。

① 环境 token 必须 mask

tool result、用户追问、observation 都不是 policy 的动作。mask 变成花斑状后,所有 mean 的分母、GAE 的递推边界都要按「连续 mask=1 的段」来处理,不能简单地当成一整条序列递推。

② terminal-only reward 是 critic 的地狱模式

整条轨迹只有最后一个 token 有非零 reward,中间步骤的 δ_t 退化成纯粹的 v_{t+1} − v_t。所有信号都得靠 critic 自己外推 —— critic 不准,advantage 就全是噪声。

③ 合取式终局 reward 会整体压低轨迹

「一步错 → 整条 = 0」意味着所有 token 拿到同号的负 advantage,policy 被整体压下去,而不是定位到出错那一步。这时 baseline 是刚需:绝对值不重要,相对差才是信号。GRPO 的组内归一化在这类稀疏终局 reward 上往往比 PPO 更好训。

④ λ 需要重新标定

单轮 4~500 token 用 λ=0.95 没问题。轨迹长到几千 token 时,λ 的衰减尺度与「错误发生点 → 终局」的距离完全不匹配,要么提高 λ 逼近蒙特卡洛,要么引入 turn-level 的中间 reward 分解。

建议做的 5 个实验

① 点「ratio ≡ 1」:L_policy 精确等于 0,因为白化后 mean(Â) = 0 —— 没动过的策略没有更新信号。② 点「critic 冷启动 v=0」:A_t 退化成纯回报,δ 只剩最后一项非零。③ 点「critic 过估」:advantage 的符号被 critic 偏差整个翻转。④ 把 β 调到 0:所有中间 token 的 r_t 归零,KL 约束消失。⑤ 把 ε 调到 0:所有 ratio≠1 的 token 全被裁平,loss 变成常数。

这个实验室没有建模的东西

只有 1 条样本、T=4、没有 batch 维、没有 mask(全部 token 有效)、没有 minibatch 切分、没有多 epoch、没有 entropy 项、没有梯度裁剪、没有优化器状态。真实的 [B, T] 上所有这些都会进来,而 mask 会把「按连续 mask=1 段分别递推 GAE」这件事变成主要复杂度(第 10 节)。

13.3 自检:能答上来就算读透了

① 为什么 logπ_old 必须在采样时存下来,不能在更新时重新前向一遍?

因为 ratio 的分母定义在采样那一刻的 θ 上。surrogate 目标的合法性来自「在 θ = θ_old 处与真目标同值同梯度」(5.0 节第 ② 步);一旦重新前向,分母就跟着当前 θ 走,ratio 恒等于 1,信任域消失,重要性加权也不再纠正任何东西 —— 数学上退化成了不带约束的 policy gradient。

在实验室里点预设「ratio ≡ 1」就是这个状态的极端版本:L_policy 恰好为 0。

② λ=0 与 λ=1 各退化成什么?为什么 λ=1 方差大?

λ=0 时 A_t = δ_t = r_t + γv_{t+1} − v_t,「未来会怎样」完全外包给 critic,所以 critic 的系统性偏差会原封不动变成 advantage 的偏差;但每一步只看一个 δ,噪声不累积,方差小。λ=1 时 A_t = Σ γ^k r_{t+k} − v_t,是纯蒙特卡洛回报减 baseline,对 critic 无偏(只要求 baseline 不依赖未来动作),但把整条尾部的随机性全吃进来,方差大。

4.4 节和 12.5 节的三行数字就是这个连续谱上的三个点:本例 λ=1 的 A₁ = 0.2006,λ=0 只有 0.0490。

③ 为什么 Â < 0 且 ratio > 1+ε 时故意不裁剪?

因为 min 取的是两项里更小的那个。Â<0 时 ratio·Â 随 ratio 增大而变得更负,永远小于被 clip 住的常数项,所以 min 自动选中未裁剪项,梯度照常回传。语义上这正是想要的:「这个 token 该被压低,结果它的概率反而涨了很多」是最需要惩罚的情形,给它设刹车等于放过了最坏的更新。

反过来 Â>0 且 ratio>1+ε 时,ratio·Â 大于常数项,min 选中常数 → 梯度为 0。所以 clip 是单边的:只阻止「朝 advantage 喜欢的方向跑太远」。

④ 把 v_t 全设成 0,advantage 会变成什么?这时 critic 等于没有吗?

会退化成未减 baseline 的折扣回报:δ_t = r_t + γ·0 − 0 = r_t,于是 A_t = Σ (γλ)^k r_{t+k}。它仍然是个合法的 advantage 估计,但少了 baseline,方差显著变大;而且本例中所有 token 的 A_t 同号(都由终局的 +0.8 主导),白化之后只剩「谁离终点更近」的形状信息,credit assignment 基本失效。

点预设「critic 冷启动 v=0」可以直接看到这个退化。对照「critic 过估 v=0.95」:那里 critic 不是缺失而是有偏,末位 token 的 δ₄ 直接变成负数,advantage 的符号被翻转 —— 比没有 critic 更危险。

⑤ 第一次 minibatch 更新时 clip 一定不生效,那 PPO 还比 vanilla PG 强在哪?

强在同一批 rollout 可以被复用多个 epoch。第一次更新时 θ 还没动,ratio ≡ 1,clip 是空转的;真正起作用的是第 2 次及以后 —— 那时 θ 已经偏移,clip 逐个 token 地把偏移限制在 ±ε 内。样本效率的提升全部来自这里:昂贵的生成只做一次,梯度更新做 k 次。

代价是信任域只是近似的(逐 token 的概率比裁剪 ≠ 序列级 KL 球),所以还需要 ε 取值、epoch 数上限、KL 监控三者一起兜底(第 8 节)。

⑥ 为什么所有 mean 的分母必须是 mask.sum() 而不是 B×T?

因为 padding 位、prompt 位、多轮场景里的 tool result 位都没有有效的 Â_t(通常是 0)。用 B×T 做分母等于把这些 0 也平均进去,loss 的量级会随「这条 batch 里有效 token 占比」浮动 —— 而占比本身随 batch 组成、response 长度分布变化。结果是等效学习率在漂移:长回答占比高的 batch 梯度大,短回答占比高的 batch 梯度小,与你想优化的东西无关。

多轮场景下 mask 变成花斑状,还要额外注意 GAE 的递推必须按「连续 mask=1 的段」分段做,不能跨段累加(第 10 节)。
