选课与学习建议

从用好 AI、开发软件，到构建智能体、训练模型和优化推理系统，按目标选择课程。

课程侧重点概念实践
CS193T提示、资料核验与独立判断1/52/5
CS146SAI 辅助需求、编码、测试与交付2/53/5
CS329Z智能体的组件、数据、优化与评估3/54/5
后训练SFT、DPO 与强化学习3/54/5
CS336从零构建语言模型、数据与训练效率4/55/5
CS2680智能体设计与推理服务优化3–4/55/5

难度以有基本编程经验为参照，5 分最难；为本站学习建议，按整门课程评估，不等于现有笔记的难度。

做网站、游戏或软件：CS193T 快速通读 → CS146S 边学边做；想自己构建智能体，再学 CS329Z，深入推理服务与性能优化则学 CS2680。

CS329Z 怎么学：重点是把检索、工具、记忆与模型组合成可评估的系统。适合有 Python 和 LLM / NLP 基础的学习者；先读这两讲，再动手搭一个小型工具智能体。

想训练自己的模型：微调现成模型可先学后训练短课；想深入预训练与训练系统，再学 CS336。CS336 强调从零实现、资源核算和实验，需要熟练 Python / PyTorch，以及机器学习、数学与基本系统知识；当前已整理前两讲。
