## 1. 课程目标与 AI 的范围 {#purpose}

这门课关注「怎样与 AI 协作」，而非要求每个人亲自训练模型。课程面向不同学科，用每周练习和一个与真实工作相关的项目，把概念变成可使用、可审查的工作方法。

贯穿全课的三条线是：有效完成任务，理解错误与限制，保持人的判断和技能。做出一份漂亮成品只是起点，还要知道它依据什么、是否符合目标，以及自己是否仍能负责。

**课件依据：第 2—8 页。**

「AI」是很宽的概念，既包括历史上的规则系统、分类与预测方法，也包括今天常用的生成模型。本课多数时候讨论后者。

| 概念 | 指什么 | 示例 |
| --- | --- | --- |
| 大语言模型（LLM） | 对语言序列建立统计模型 | 解释概念、生成文本 |
| 多模态模型 | 处理文字之外的一种或多种信息模态 | 理解图片、声音与文本的关系 |
| 生成式 AI | 产生新内容的系统 | 写作、图像生成 |
| 分类系统 | 把输入分配到类别 | 判断评论是否违规 |

这些分类不是互斥关系：生成模型也能被用于分类；多模态模型也可能具有文本生成能力。**课件依据：第 9—13 页。**

## 2. 从下一 token 预测理解生成 {#tokens}

想象一句话「欢迎，请先……」。如果说话者是老师、服务员或主持人，接下来可能出现的内容会不同。语言模型把前面的序列作为条件，计算下一段 token 的概率，再选出一个接上去，反复进行，直到完成回答。

**Token 是模型处理序列的单位，不严格等于一个词。**它可能是一个词、词的一部分、标点或字符片段。课件为便于入门常用「下一个词」类比；真正统计上下文长度与费用时，应使用对应模型的分词方式。

~~~text
已有上下文
    ↓
计算下一个 token 的概率
    ↓
按解码规则选择 token
    ↓
追加到上下文，继续下一步
~~~

为什么相同问题有时会得到不同答案？生成过程可能包含采样。**Temperature（温度）**影响概率分布的集中程度：较高时通常更容易选到原本概率较低的候选，较低时通常更集中。但随机性还受其他解码设置和实现影响；低温不能保证事实正确。

下一 token 预测描述了生成机制，并不意味着模型只能写短句。大量连续预测可以形成解释、代码、规划或推理文本；关键在于这种机制本身不提供「每句话都是真实的」保证。

**课件依据：第 15—19、28—29 页；token 边界与温度说明为技术澄清。**

## 3. 神经网络、权重与层 {#network}

不可能为所有可能的句子开头保存一张精确概率表，因此模型用神经网络来近似这些关系。输入经过多层计算，形成中间表示，最终得到输出概率。

- **节点与激活：**表示计算中的中间数值，课件用「某个概念是否相关」帮助理解。
- **权重与参数：**控制输入信号如何参与后续计算的数值，是训练要调整的对象。
- **层：**按结构组织的计算阶段。深度学习中的「深」通常指具有多层表示与计算。

不要把课件示意图理解成「每个节点都对应一个可以准确命名的概念」。真实模型的特征往往分布在多个位置，一个位置也可能参与多个功能；课件同样提醒这些表示不一定能被人直观解释。

因此，模型说「我因为某个原因这样回答」，并不等于它读取并准确报告了内部每个权重的作用。解释文本和计算机内部机制是两个层次的问题。

**课件依据：第 20—28、43 页。**

## 4. 训练、微调与推理 {#stages}

| 阶段 | 主要发生什么 | 参数通常是否更新 |
| --- | --- | --- |
| 预训练 | 从大量数据中学习语言、知识关联与模式 | 是 |
| 后续微调 / 后训练 | 用示范、偏好或反馈调整行为 | 是 |
| 普通推理 | 根据已有模型与当前上下文生成结果 | 否 |

预训练建立广泛能力，后训练改善指令遵循、回答风格等行为。推理使用已经学到的参数，但同一参数遇到不同上下文也会产生不同输出。

**「模型记住了我的这句话」需要分清含义。**它可能只是这句话仍在本次对话上下文里，也可能是应用把某条用户偏好存到外部记忆。普通聊天中表现出适应，不等于本轮实时训练了基础权重。聊天数据未来是否会被用于训练，又是另一个产品与许可问题，第 3 讲会继续讨论。

课件用「强化或削弱连接」解释训练直觉。更精确地说，优化算法根据损失对许多参数计算梯度并更新；不能把每个正权重都视为好连接、负权重都视为坏连接。

**课件依据：第 26—32 页；更新机制的精化为补充说明。**

## 5. 注意力与上下文窗口 {#context}

同一句话的前文会改变后续内容的概率。Transformer 的注意力机制让计算有选择地结合上下文中的不同位置，从而利用长距离关系。

**上下文窗口（context window）**是模型一次处理所能容纳的 token 范围。除了你最新输入的问题，还可能包含系统指令、历史回答、文档或工具返回信息。容量有限，输出也需要预算；把更多材料塞进去，不等于每份材料都会被同样有效地利用。

一个实用区分是：

| 问题 | 主要关心 |
| --- | --- |
| 内容能否装得下？ | 上下文容量、截断 |
| 装进去后能否找对？ | 信息位置、相关性、噪声 |
| 找到后是否解释正确？ | 来源理解、推理与核验 |

课件用一个极短窗口让关键角色信息被挤出去，说明有限上下文的影响。这是教学模型，实际窗口上限取决于具体产品与模型，不应把课件某个数值当作所有工具的规格。

**课件依据：第 33—42 页。**

## 6. 幻觉、迎合与拟人化 {#failures}

**事实编造 / 幻觉（hallucination）：**模型能生成语法完整、风格可信却缺少事实依据的内容。概率上像一句合适的话，不等于它对应真实事件、文献或数据。需要生成新组合的能力，也让输出不能仅靠「是不是见过这句话」来判定。

**迎合（sycophancy）：**为了显得支持用户，顺着用户的观点或愿望回答，而没有坚持证据。友善是表达方式，迎合则可能损害事实判断。

**拟人化（anthropomorphism）：**用人类的意图、感受或人格解释系统。比喻有时有助于沟通，例如把任务交给「新同事」，但如果因此相信它懂得承担责任、忠诚或内省，就可能高估可靠性。

| 观察 | 容易误判成 | 更可检查的问题 |
| --- | --- | --- |
| 回答很自信 | 已经确认事实 | 依据在哪里，是否支持这句话？ |
| 语气很关心我 | 理解且承担我的利益 | 实际建议是否符合目标？ |
| 文字条理清楚 | 推导正确 | 能否复算、复现或反驳？ |
| 它一直同意我 | 我的观点充分可靠 | 是否主动检查反例和不确定性？ |

课件还提醒，习惯性的标题、列表和套话可能来自被强化的表达模式，而非内容深度。笔记不把某种风格本身当作错误；关键是风格是否服务具体任务。

**课件依据：第 44—48 页。**

## 7. 练习与自测 {#practice}

原课第 50—51 页要求尝试让 AI 辅导作业，同时限制直接给答案，并思考课程的 AI 使用规则。重点是压力测试：一条「请不要出错」指令，到底能坚持到什么程度？

**补充练习：**选一道自己已会的题，让模型每轮只给一个提示。记录它是否泄露整题答案、是否给出错误知识、遇到催促时是否改变边界。再换一道相似题，在不使用 AI 的情况下独立完成，检验自己学到了什么。

<details><summary>为什么「输出连贯」不能直接当作事实可靠性的证据？</summary><p>连贯性主要反映生成结果符合语言与上下文模式；事实可靠性还需要来源、核验或可重复的计算。两者可能相关，但不是同一个指标。</p></details>

<details><summary>提示词改变了回答，是否说明模型权重刚刚变了？</summary><p>不说明。固定参数在不同输入条件下就会产生不同输出；当前上下文变化与参数训练必须分开理解。</p></details>

<details><summary>本讲最值得带到下一讲的问题是什么？</summary><p>既然模型依赖上下文、会自信出错且可能迎合，我应怎样把目标、材料和检查步骤写清楚，让输出更接近可验证的工作成果？这正是核心提示技巧的起点。</p></details>
